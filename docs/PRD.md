## 1. 产品概述

### 1.1 背景与机会
小红书、Instagram、lofter 等社区出现一种以 **colour walk / 色彩日记 / 色块拼贴** 为核心的内容流派，用户拍下一张有主导色的照片，再配一块「纯色 + 时间戳 + 英文色名」的色块，组合成极具审美辨识度的九宫格单图。目前这类内容高度依赖 **PS / 醒图 / 稿定** 等通用工具，缺少一款**围绕色彩和拼贴专门打磨**的小众美学工具。

### 1.2 产品定位
**浮光 Shimmer** 是一款浏览器端（Web Canvas）的小众美学创意图片设计工具，围绕「色彩」与「拼贴」两个关键词，为用户提供**低门槛、高审美、强风格化**的图片生成能力。

- 不做「万能修图」，不做「一键滤镜」。
- 做「从一张照片出发，自动长出一组有审美主张的作品」。
- 名字取意：照片是生活里一闪而过的浮光，值得被留住、被重新拼贴成作品。

### 1.3 目标用户
| 人群 | 画像 | 核心诉求 |
| --- | --- | --- |
| 小红书文艺博主 | 20–35 岁，女性居多，关注摄影/穿搭/生活方式 | 快速出图、风格统一、能形成个人视觉标签 |
| 独立设计师 / 学生 | 有审美但不想每次打开 PS | 轻量、可控、导出高精度源文件 |
| Vlogger / Gif 爱好者 | 输出动态素材 | 支持 GIF 输入输出，保留动效 |

### 1.4 一句话价值
> **Shimmer — a shimmer of color, captured in a moment.**
> 上传一张照片，收一片属于你的浮光。

## 2. 核心概念

### 2.1 两种核心玩法
基于参考图抽象出两条主线，底层是同一个**画布 + 图层**系统：

#### 玩法一：色块拼接 (Color Block)
> 对应参考图 ①。上传一张图 → 自动识别主题色 → 输出「色块 + 原图」的双段拼接。

- 最小玩法，3 秒出图。
- 色块上可加英文色名 + 时间戳（`yellow, 13:22PM` 这类）。

#### 玩法二：创意拼贴 (Creative Collage)
> 对应参考图 ②③。在色块拼接的基础上，色块层可以被「图形 / 文字」**镂空**或**叠加**。

- 镂空雨滴、爱心、水滴（参考图 ②）
- 镂空/重复文字（参考图 ③）
- 波点、涂鸦线条装饰
- 手写衬线英文标签（"Spring"、"Tahiti Cream Grapes"）

### 2.2 设计原则
1. **等比原则**：任何上传图都不变形，画布通过色块来"补齐"构图。
2. **色彩优先**：主色永远来自图片本身，不鼓励手动选色（但允许微调）。
3. **少即是美**：预置模板少而精，避免「素材堆砌感」。
4. **可动可静**：支持 GIF，导出时保留动效。

## 3. 画布与图层模型（核心数据结构）

所有功能都围绕一个**标准化画布**构建。

### 3.1 画布 (Canvas)
```ts
interface Canvas {
  id: string;
  ratio: '3:4' | '4:3' | '1:1' | '9:16' | '16:9' | 'custom';
  width: number;       // 最终导出像素
  height: number;
  background: Color;   // 兜底色
  layout: Layout;      // 上下 / 左右 / 四宫格 / 自由
  layers: Layer[];     // 自下而上
  isAnimated: boolean; // 是否包含 GIF
}

type Layout =
  | { type: 'split-v'; ratio: number }   // 上下，ratio 为上段占比
  | { type: 'split-h'; ratio: number }   // 左右
  | { type: 'grid'; rows: number; cols: number }
  | { type: 'free' };                    // 完全自由拖拽
```

### 3.2 图层 (Layer)
统一图层协议，便于扩展：
```ts
interface BaseLayer {
  id: string;
  name: string;
  visible: boolean;
  locked: boolean;
  transform: { x: number; y: number; w: number; h: number; rotate: number };
  opacity: number;
  blend?: 'normal' | 'multiply' | 'screen';
}

type Layer =
  | ImageLayer      // 原图（静态/GIF）
  | ColorBlockLayer // 主色块
  | ShapeLayer      // 预置/上传图形
  | MaskLayer       // 作用于 ColorBlockLayer 的镂空蒙版
  | TextLayer;      // 英文/时间戳/手写装饰
```

### 3.3 图层之间的关系
- **MaskLayer 依附于 ColorBlockLayer**：镂空是"从色块中挖出图形"，不是单独一个形状层。
- **ShapeLayer 可以作为实色装饰**（参考图② 的绿色雨伞涂鸦），也可以**被升格为 MaskLayer**（参考图② 的雨滴是镂空的）。
- 一个 ColorBlockLayer 可以叠加多个 MaskLayer（支持"一堆水滴镂空"）。

> 关键判断：**「镂空」和「叠加实色」是同一个 Shape 的两种渲染模式**，用户通过一个开关切换，不引入两套概念。

## 4. 功能模块

### 4.1 模块总览
```
 ┌───────────────────────────────────────────────────┐
 │                      Canvas Editor                │
 ├───────────┬───────────────────────────┬───────────┤
 │  左侧:    │       中间: 画布预览      │  右侧:    │
 │ 素材/图层 │   (等比、实时、可缩放)    │ 属性面板  │
 └───────────┴───────────────────────────┴───────────┘
```

### 4.2 M1 上传 & 主色识别
| 子功能 | 说明 | 优先级 |
| --- | --- | --- |
| 支持格式 | JPG / PNG / WebP / **GIF** / HEIC | P0 |
| 上传方式 | 点击、拖拽、粘贴 (Ctrl+V)、剪贴板 | P0 |
| 主色识别 | 调色板 Top-5（基于中位数剪裁 + K-means / median-cut 算法） | P0 |
| 色名标注 | 自动匹配最接近的 **英文色名**（如 `mustard`, `lavender`）+ 当前时间 | P0 |
| 手动调色 | 用户可以吸管重选、或从 5 色调色板里切换 | P1 |
| GIF 处理 | 抽取首帧识别主色；编辑态用首帧预览，导出保留动效 | P0 |

**交互细节**
- 上传后 **2 秒内** 必须给出一张可用的初稿（默认"上下二分 · 上色块下原图"）。
- 色名避免机翻感：内置一个 ~200 词的英文色名词典（mustard, sage, dusty pink, cobalt…）。

### 4.3 M2 色块拼接 (玩法一)
核心就是 `Canvas.layout` + `ColorBlockLayer` + `ImageLayer` + 可选 `TextLayer`。

**用户可调**
- **布局**：上下 / 左右 / 上下上 / 左右左 / 田字格（最多 4 格）
- **比例**：拖拽分隔线调整每段占比；**原图始终不变形**，多余部分被色块补齐 / 覆盖（有两种模式：`contain` 留白 vs `cover` 裁切）
- **色块颜色**：来自主色面板，可切换
- **文案**：关/开 英文色名 · 关/开 时间戳 · 自定义一行小字
- **字体**：预置 4 套（衬线斜体 / 手写体 / 等宽 / 极简无衬线）

**示例模板（内置预设）**
- `Diary · 上色块下原图 + 色名@时间戳`（对应参考图①）
- `Stack · 三段拼接`
- `Frame · 原图居中 + 四周色块包围`
- `Mirror · 左图右色块 + 竖排英文`

### 4.4 M3 创意拼贴 (玩法二)
在 M2 基础上新增 **图形 / 文字蒙版** 系统。

#### 4.3.1 图形库
分三组：
| 组 | 内容 |
| --- | --- |
| **Dots & Drops** | 圆点、椭圆点、水滴、雨滴、露珠 |
| **Icons** | 五角星、爱心、音符、太阳、月亮、云、花朵 |
| **Doodles** | 雨伞、波浪线、涂鸦箭头、手绘边框 |

- 每个图形都是 **SVG**，天然矢量、可缩放无损。
- 支持一键 **阵列化**（点击"雨滴"→ 色块上随机撒 20 个雨滴，可调密度、大小分布、旋转角度）。

#### 4.3.2 文字作为蒙版（对应参考图③）
- 输入任意文字（如 `water`），选择字体、大小范围。
- 一键生成"文字云阵列"，铺满当前色块。
- 支持**镂空**（文字挖空色块露出原图）或**纯色重复**两种渲染。

#### 4.3.3 用户上传图形
- 支持用户上传 PNG / SVG / JPG 图形作为"自定义元素"。
- 对 **PNG/JPG**：自动做 **抠图/二值化** → 转 SVG 轮廓 → 进入素材库（走浏览器端 `potrace` 或等价算法）。
- 识别结果展示"轮廓预览"，让用户在「保留原图」和「使用轮廓」两种方式间选择。

#### 4.3.4 蒙版开关（关键交互）
每个 ShapeLayer 右侧属性面板有一个开关：

```
 Fill Mode:
  ( ) Solid  ── 纯色实心图形，叠在色块上
  (•) Cutout ── 从色块里镂空，露出下层图片
  ( ) Photo  ── 图形内部显示上传原图的对应区域
```

> 这是**整个创意拼贴玩法的核心抽象**，用户只需要理解一个开关。

### 4.5 M4 文字与装饰
- 多语言文字（英文/中文/日文），预置 8 套**审美向字体**（拒绝系统默认字体）。
- 支持曲线/弧形排版（用于"Spring"那种弧形装饰文字）。
- 支持手写笔刷线条（涂鸦）：iPad/触控/鼠标皆可，保存为矢量路径。

### 4.6 M5 GIF 支持
- **输入**：上传 GIF 时保留全部帧，主色识别走首帧。
- **编辑**：画布只渲染首帧预览（保证性能），右下角有一个"播放预览"按钮预览动效。
- **输出**：
  - 若原图是 GIF、且画布中存在对 GIF 层的遮罩/色块覆盖：导出为 GIF（逐帧应用图层合成）。
  - 若静态元素 > 动态元素（例如只有标题有跑字动画）：可选输出 GIF / WebP / MP4。
- **性能兜底**：超过 60 帧自动降采样，超过 10MB 自动压缩，提前告知用户。

### 4.7 M6 导出与分享
- 导出格式：PNG（透明）/ JPG（高质）/ GIF / WebP。
- 尺寸：`1x / 2x / 3x`、或自定义像素。
- 一键适配社交尺寸：小红书 `3:4` · Instagram `1:1` · 朋友圈长图 `9:16`。
- 导出历史：最近 20 份作品保存在 IndexedDB，可回溯编辑。

## 5. 用户旅程（Happy Path）

```
 1. 打开首页
   └─ 大面积色卡背景 + 一句 slogan + 一个「Drop your photo」虚线框

 2. 拖入一张照片
   └─ 2s 内出现默认作品：上色块下原图 + 色名@时间戳
   └─ 主色调色板在顶部弹出，展示 5 个候选主色

 3. 用户点「创意拼贴」Tab
   └─ 左侧素材库展开：Dots / Icons / Doodles / Text Mask / Upload
   └─ 用户点「水滴」→ 色块上撒一片水滴镂空

 4. 用户改文字 `yellow, 13:22PM` → `lavender, Apr 22`
   └─ 字体在右侧切换为「衬线斜体」

 5. 用户点导出
   └─ 选 `3:4 · 小红书` → PNG 2x → 下载
```

**关键体验指标**
- 首次出图 ≤ 3s
- 画布操作 FPS ≥ 50
- 导出一张 2000×2667 PNG ≤ 1.5s
- GIF 导出 100 帧 1080p ≤ 15s

## 6. 视觉与交互规范（Design DNA）

### 6.1 气质锚点
| 维度 | 方向 |

| 形容词 | 克制、纸本感、文艺、日记本、色彩敏感 |

- 主背景：`#FAFAF7`（米白纸感）
- 主文字：`#111111`
- 强调色：跟随用户当前作品主色（动态主题）

- UI：`Inter` / `PP Neue Montreal`
- 创作字体库（供用户使用）：至少包含 `DM Serif Display Italic`, `EB Garamond`, `Homemade Apple`, `JetBrains Mono`, `思源宋体`, `霞鹜文楷`。

- 桌面：三栏（素材 / 画布 / 属性），最优体验。
- 平板：两栏（画布 + 抽屉式素材/属性面板）。
- 移动端：单栏 + 底部 Tab，画布全屏，素材/属性以 BottomSheet 形式唤起。

## 7. 技术方案概要

### 7.1 技术栈
- **框架**：Next.js 15 (App Router) + React 19 + TypeScript
- **画布**：`Fabric.js` 或 `Konva.js`（评估后选 Konva，理由：性能更好、图层 API 更现代）
- **主色提取**：`colorthief` + 自研 `median-cut` fallback；Web Worker 跑算法
- **图形库**：内置 SVG 图标集（Lucide + 自绘）+ `svgo` 运行时精简
- **PNG → SVG**：`potrace-wasm`（浏览器端位图描边）
- **GIF**：`gifuct-js` 解析 + `gif.js` / `gifenc` 编码
- **状态**：Zustand（画布 + 图层），历史记录走 `zundo`
- **样式**：Tailwind v4 + shadcn/ui
- **持久化**：IndexedDB (`idb-keyval`)，未登录态即可保存

### 7.2 渲染架构
```
 ┌─ ReactUI (控件 / 属性面板)
 │   ↓ dispatch
 ├─ Zustand Store (Canvas + Layers)
 │   ↓ subscribe
 ├─ KonvaStage (主画布)
 │   ├─ ImageLayer   (Konva.Image / GIFPlayer)
 │   ├─ ColorBlockLayer + MaskGroup (clipFunc)
 │   ├─ ShapeLayer   (Konva.Path from SVG)
 │   └─ TextLayer    (Konva.Text)
 └─ Export Worker (OffscreenCanvas → PNG/GIF)
```

### 7.3 关键算法要点
- **主色识别**：RGB → Lab → K-means(k=5)，按簇内像素数排序；剔除接近纯黑纯白的簇。
- **英文色名匹配**：Lab 空间最近邻，匹配预置 ~200 色命名表。
- **蒙版镂空**：使用 Konva `clipFunc` 或 SVG `<mask>`；对多图形合并使用 `boolean path operations`（paper.js）。
- **GIF 合成**：逐帧把其它层光栅化再与 GIF 帧做 `drawImage` 合成，最后用 `gifenc` 编回。
- **PNG→SVG**：`potrace-wasm` 阈值可调，识别结果给用户预览再确认。

## 10. 开放问题 (Open Questions)

1. **是否做账号体系？** MVP 建议无需登录，靠 IndexedDB 保存作品；若做社区则需要。
2. **是否引入 AI 辅助？** 例如"自动给这张照片取一个色名故事"、"根据主色推荐一首歌"，属于锦上添花但可延后到 M4+。
3. **模板生态**：是否允许用户提交模板？需要审核流程。
4. **GIF 性能上限**：超大 GIF（>30MB，>200 帧）是否直接拒绝上传，还是后端代处理？暂按拒绝上传处理。
5. **字体版权**：商用字体授权由谁承担？优先使用开源字体 + SIL Open Font License 系列。

## 11. 附录

### 11.1 术语表
- **主色 / Theme Color**：通过 K-means 从图片中提取的视觉主导色。
- **色块 / Color Block**：画布中以主色填充的一块固定区域。
- **镂空 / Cutout**：图形作为蒙版从上层色块中挖空，露出下层图片。
- **文字云阵列 / Text Mask**：将一个词以多尺寸、随机排布铺满色块，作为蒙版或装饰。

### 11.2 参考图映射
| 参考图 | 对应玩法 | 用到的图层 |
| --- | --- | --- |
| ① 黄色番茄 + `yellow, 13:22PM` | 玩法一（色块拼接） | Image + ColorBlock + Text |
| ② 紫色雨伞涂鸦 + 镂空雨滴 | 玩法二（创意拼贴 / 镂空 + 装饰） | Image + ColorBlock + Shape(Doodle) + Mask(Cutout 雨滴) + Text |
| ③ `water` 文字阵列 | 玩法二（创意拼贴 / 文字蒙版） | Image + ColorBlock + Mask(TextArray) |
